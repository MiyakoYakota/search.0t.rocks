INSTANCE INFORMATION

Data handling

This software runs against a collection selected by its operator.

Application behavior

The application sends search terms to its configured Solr backend. It displays returned records to authorized users. Browser assets are served by this instance, and this version includes no analytics, advertising, payment service, or cloud export integration.

Local traces

Search terms can appear in the browser's history because search uses GET requests. HTTP responses disable caching, but that does not erase history or stop screenshots. Reverse proxies, infrastructure, backups, and monitoring have their own logging and retention settings.

Operator responsibilities

The instance operator controls datasets, access, lawful use, retention, corrections, deletion, and incident handling. Use only data you are authorized to process. Configure TLS for remote access and a clear operator contact before importing real records.
